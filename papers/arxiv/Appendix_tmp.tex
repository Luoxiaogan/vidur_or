\subsection{Proof of Proposition~\ref{prop:large_rate}}\label{appendix::proof of fluid lower bound}
When $\lambda_jd_1l_j^{\prime}\left( l_j + \frac{l_j^\prime}{2} \right)\geq 1$, consider the number of prompts in a batch is $n_j$. If the equilibrium still holds, the number of prompts at stage $0 \to l_j^\prime-1$ is $n_j/l_j^\prime$, and the memory consumption of the batch is that
$$M_j = \frac{n_j}{l_j^\prime}\sum_{i=0}^{l_j^\prime-1}\left( l_j +i \right) = n_j \left(l_j + \frac{l_j^\prime-1}{2} \right)$$
Then the time to process the batch is that
$$\text{Processing Time}_j = d_0+d_1M_j=  
 d_0+d_1n_j \left(l_j + \frac{l_j^\prime-1}{2} \right)
$$
During the processing of the batch, the number of the arrival prompts is that
$$\text{Arrival}_j =\text{Processing Time}_j \cdot \lambda_j= 
 d_0\lambda_j+\lambda_jd_1n_j \left(l_j + \frac{l_j^\prime-1}{2} \right)$$
And the number of completion prompts is that
$$\text{Completion}_j = \frac{n_j}{l_j^\prime}$$
Estimating the gap gives that
\begin{align}
    \text{Arrival}_j-\text{Completion}_j  &= d_0\lambda_j+\lambda_jd_1n_j \left(l_j + \frac{l_j^\prime-1}{2} \right) - \frac{n_j}{l_j^\prime}\geq d_0\lambda_j\label{inequality::fluid lower bound}
\end{align}
Notice that (\ref{inequality::fluid lower bound}) holds for all $n_j>0$, which means that the length of the queue corresponding to the batch iteration $N$ as well as to the time $T(N) = N \cdot \left(d_0+d_1n_j\left(l_j + \frac{l_j^\prime-1}{2}\right)\right)$ is that
$$\text{Queue Length}\left(T(N)\right) \geq d_0\lambda_j\cdot N$$
So the latency of the prompt arrived at $T(N)$ is at least 
$$\text{Latency}^{T(N)} \geq  \left(\frac{d_0\lambda_jN}{n_j\left(l_j + \frac{l_j^\prime-1}{2} \right)}+1\right)\cdot \left( 
 d_0+d_1n_j \left(l_j + \frac{l_j^\prime-1}{2} \right) \right)\to \infty,\;N\to \infty$$


\subsection{Proof of Proposition~\ref{prop::online policy expected throughput upper bound, multiple type}}\label{appendix::proof online policy expected throughput upper bound, multiple type}
We consider the multiple-type fluid model, and the calculation gives that
$$\Delta T = \frac{d_0}{ 1- d_1\sum_{j=1}^m \lambda_j(l_j^\prime+1)\left( l_j + \frac{l_j^\prime}{2} \right) },\,n_j^* = \Delta T\cdot \lambda_j(l_j^\prime+1)\left( l_j + \frac{l_j^\prime}{2} \right) ,\, M^* = \Delta T \cdot \sum_{j=1}^m \lambda_j(l_j^\prime+1)\left( l_j + \frac{l_j^\prime}{2} \right),\,$$
Here, $\Delta T$ denotes the time of one iteration for batch consisting of exact $n_j^*/(l_j'+1)$ of type $j$ prompts at each stages ($0,1,\dots,l_j'$). Since in the steady system, the processing time of a batch is equal to the time cost to arrive as many prompts as the completion. Denote $\text{Average Arrival}_j^T$ as the average arrivals of type $j$ prompts over time horizon $[0,T].$ the So we have that
$$\sum_{j=1}^m\ex{}{ \text{Average Arrival}_j^T }\cdot l_j'=  \sum_{j=1}^m\text{Average Arrival}_j^T \cdot l_j'= \lambda_jl_j' = \throughput^* $$
In stochastic setting, the average throughput is not greater than
\[ 
\sum_{j=1}^m\text{Average Arrival}_j^T \cdot l_j'.
\]
By taking expectation of the total arrivals and taking average over time yields 
$$\ex{}{\throughput^{(\pi,T)}}\leq \ex{}{\sum_{j=1}^m\text{Average Arrival}_j^T\cdot l_j'}=\ex{}{\throughput^*}  $$



\subsection{Proof of Proposition~\ref{prop:lower_bound_FCFS}}\label{appendix::proof of lower bound of of FCFS}
We just need to give an example of prompt types where the FCFS meets the throughput gap of $\Omega(T)$.Consider there are two types of prompts, where prompts of type $1$ with $l_1=1, l_1^\prime=1, \lambda_1=1$ and prompts of type $1$ with $l_2=1, l_2^\prime=2, \lambda_2=1$. \\
Firstly, we compute the fluid model, and the total memory usage and equilibrium equations are given by
$$M = 1.5n_1+2n_2,\, d_0+d_1\cdot (1.5n_1+2n_2) = \frac{n_1}{2}=\frac{n_2}{3}$$
Thus
$$K = \frac{d_0}{1-9d_1},\, n_1 = 2K,\, n_2=3K,\, M=9K$$
where $K$ represents the time cost of the batch inference. Without loss of generality, we set $K=1$, then $n_1=2, \,n_2=3,\,M=9 $. \\
Secondly, we consider the stochastic case, where $X_i^{(t)}\overset{i.i.d}{\sim} P(1), i=1,2$. Assume that at time $t$, the system is in equilibrium, Equilibrium batch at time $t$:
\begin{itemize}
    \item Type $1$:
    \begin{itemize}
        \itemsep0em
        \item $1$ prompt in stage $0$, memory = $1$, just get prefilled
        \item $1$ prompt in stage $1$, memory = $2$, the memory will be cleared
    \end{itemize}
    \item Type $2$:
    \begin{itemize}
        \itemsep0em
        \item $1$ prompt in stage $0$, memory = $1$, just get prefilled
        \item $1$ prompt in stage $1$, memory = $2$
        \item $1$ prompt in stage $2$, memory = $3$, the memory will be cleared
    \end{itemize}
\end{itemize}
Then we consider the number of arriving prompts of each type $(X_1^{(t)}, X_2^{(2)})$. The combinations that will not lead memory to exceed $9$ in two batch iterations are $(0,0),\,(1,0),\,(0,1),\,(1,1),\,(2,0)$, so the probability of other combinations is 
$$p = 1 - \frac{1}{e^2}- \frac{1}{e^2}- \frac{1}{e^2}- \frac{1}{e^2}- \frac{1}{2e^2}=1- \frac{9}{2}e^{-2} \approx 0.391 $$
This means that even under optimal conditions where the system is in equilibrium at $t$, there is still a probability of $p = 0.391$ of memory overflow in $2$ time steps, which will lead to at least $1$ additional queue length of type $2$ in $2$ time steps. So the queue length of type $2$ at $t$ has a lower bound:
$$\text{Queue Length}_2(t) \geq 0.3t$$


\subsection{Proof of Theorem~\ref{thm:wait_heavy_traffic}}\label{appexidx::proof of wait_heavy_traffic}
First we consider the single-type case, and prove some useful lemmas.
\subsubsection{Single-Type}

First, consider the single-type scenario. It can be inferred from the recursion that the waiting time is necessarily spent on awaiting the accumulation of sufficient prompts for prefill.
\begin{lemma}\label{lemma::throughput gap, single}
The number of incoming prompts $X^t$ at each time step $t$ follows a Poisson distribution with parameter $\lambda$. The service processes up $\lambda$ prompts at each time step when there are at least $\lambda$ prompts available. Let $W^t$ represent the number of prompts in the queue at time $t$, starting with $W_0=0$. The state transition rule is given by
$$W^{t+1}=W^t+X^t-\lambda\cdot \mathbf{1}\{W^t+X^t\geq \lambda\}$$
Define the total number of stuck time steps as $T_{\text{stuck}}$, which is also the total number of time steps of $W^t+X^t<\lambda$, and the following relationship holds
$$\mathbb{E}[W^T]= \lambda\cdot\mathbb{E}[T_{\text{stuck}}].$$
\end{lemma}
Detailed proof is in Appendix~\ref{appendix_lemma::proof of throughput gap, single}. In order to estimate the expected upper bound, we need to construct a coupled process to dominate $W_t$.

\begin{lemma}\label{lem:coupled_process, single}
Define a new process $\{\tilde{W}^t\}$ as a coupled version of $\{W^t\}$ as follows:
$$
\tilde{W}^0 = 2\lambda, \quad \tilde{W}^{t+1} = \max\{ 2\lambda, \tilde{W}^t + X^t - \lambda \}.
$$
Then, we have $\tilde{W}^t \geq W^t + \lambda, \;\forall t\in \mathbb{N}$.
\end{lemma}
Detailed proof is in Appendix~\ref{appendix_lemma::proof of coupled_process, single}. Next, by Proposition 6.3 in \cite{asmussen2003applied}, we have that 
\begin{lemma}
    $$\tilde{W}^T=2\lambda+\max(S_T, S_T-S_1,\cdots,S_T-S_{T-1},0),\; S_k=\sum_{r=1}^k (X^r-\lambda) $$
\end{lemma}
Let $\xi^k = X^k-\lambda$, and notice that 
$$\max(S_T, S_T-S_1,\cdots,S_T-S_{T-1},0)=\max_{1\leq k\leq T}(\sum_{r=k}^{T}\xi^r)^+\overset{d}{=}\max_{1\leq s\leq T}(\sum_{r=1}^{s}\eta^r)^+, \; \eta^r\overset{d}{=}X^1-\lambda$$
So we have that $\tilde{W}^T \overset{d}{=}2\lambda+\max_{1\leq s\leq T}(\sum_{r=1}^{s}\eta^r)^+ $. 

Since $\tilde{W}^T \geq \lambda+W^T$, we have $\mathbb{E}[W^T]\leq \mathbb{E}[\tilde{W}^T]-\lambda = \mathbb{E}[\max_{1\leq s\leq T}(\sum_{r=1}^{s}\eta^r)^+]+\lambda$. Let $Y^T = \max_{1\leq s\leq T}(\sum_{r=1}^{s}\eta^r)^+$, consider the expectation $\ex{}{Y^T}$.
By Lemma 2 in \cite{strait1974maximum}, we get that
\begin{lemma}\label{lem:Y_T}
    $$\ex{}{Y^T}=\ex{}{\max_{1\leq s\leq T}(\sum_{r=1}^s\eta^r)^+}=\ex{}{\max_{1\leq k\leq T}S_k^+}=\sum_{k=1}^T \frac{1}{k}\ex{}{S_k^+}$$
\end{lemma}
Then we consider the $\mathbb{E}[S_k^+]$, and just use Cauchy's inequality
\begin{align*}
&\mathbb{E}[S_k^+]=\mathbb{E}[\max\{S_k,0\}]\leq \ex{}{|S_k|}\leq \sqrt{\ex{}{S_k^2}}=\sigma\sqrt{k}=\sqrt{\lambda k}\\
\Rightarrow& \ex{}{Y^T}\leq \sqrt{\lambda}\sum_{k=1}^T \frac{1}{\sqrt{k}} \sim \sqrt{\lambda T}
\end{align*}
So we have that 
\begin{lemma}\label{lemma::throughput gap}
    $$\mathbb{E}[W^T]-\lambda\leq \mathbb{E}[Y^T]\leq  \sqrt{\lambda} \sum_{k=1}^T \frac{1}{\sqrt{k}} \sim\sqrt{\lambda T},\; T\to \infty$$
\end{lemma}
Then consider the average throughput. In the deterministic scenario, the average throughput $\throughput^* = \lambda$. Thus, in the stochastic case, the expected gap between the average throughput $\throughput$ and $\throughput^*$ is given by $\frac{1}{T}\mathbb{E}[W^T]$.\\
% In \textbf{Many-Server Heavy-Traffic} case, 
% \begin{align*}
%     \frac{1}{T^{\zeta}}\ex{}{W^{T,\zeta}}=\frac{\lambda^{\zeta}+\sqrt{\lambda^{\zeta}T^{\zeta}}}{T^{\zeta}}=\frac{\zeta\lambda+\sqrt{\zeta\lambda \zeta T }}{\zeta T}=\frac{\lambda+\sqrt{\lambda T}}{T}\to 0,\; T\to \infty
% \end{align*}
In \textbf{Conventional Heavy-Traffic} case, 
\begin{align*}
    \frac{1}{T^{\zeta}}\ex{}{W_T^{\zeta}}=\frac{\lambda^{\zeta}+\sqrt{\lambda^{\zeta}T^{\zeta}}}{T^{\zeta}}=\frac{\lambda+\sqrt{\lambda \zeta T }}{\zeta T}\to 0,\; \zeta\to \infty 
\end{align*}

\subsubsection{Multiple-Type}

When the memory constraint $C\geq M^*$, consider the WAIT policy $\pi$, which is defined by the $[n_1,\cdots,n_m]$, where $n_j$ represents the threshold of the number of prompts of type $j$ in each stage.

Solving the linear system:
$$d_0+d_1\sum_{j=1}^m n_j(l_j^\prime+1)\left(l_j+\frac{l_j^\prime}{2}\right)\leq \frac{n_j}{\lambda_j},\,M^{\pi} = \sum_{j=1}^ma_j(l_j^\prime+1)\left(l_j+\frac{l_j^\prime}{2}\right)\geq  M^*$$
we obtain the policy class $\Pi$, each $\pi = [n_1,\cdots,n_m]\in \Pi$ with corresponding memory capacity $M^{\pi} \geq  M^*$.

$\forall \pi \in \Pi$, when prompts of all $m$ types are in the same batch, $\text{Arrival}_j\leq \text{Completion}_j$. Indeed, when type $j$ is in the batch, no matter what the other types are in the batch, we have that $\text{Arrival}_j\leq \text{Completion}_j$. Specifically, when $M^\pi = M$, the policy is $\pi = [ \frac{n_1^*}{l_1^\prime+1},\,\cdots,\,\frac{n_m^*}{l_m^\prime+1} ]$. 

Now we define some notations. Let $s$ denote the batch index, $J^s$ denote the types contained in the $s$-th batch, $s(J^s)$ denote the time at the start of the inference of the $s$-th batch and $e(J^s)$ denote the time at the end of the inference of the $s$-th batch. Note that $s(J^{s+1})-e(J^s)$ denotes the waiting time before $s+1$-th batch, this waiting condition only occurs when all $m$ types do not satisfy the threshold.

At $s+1$-th batch, the state transition rule is given by
$$W_{(j)}^{e(J^{s+1})}=W_{(j)}^{e(J^s)}+X_{(j)}^{s(J^{s+1})-e(J^{s})}+Y_{(j)}^{e(J^{s+1})-s(J^{s+1})}- n_j\cdot \mathbf{1}\{j\in J^{s+1}\} ,\,\forall j  = 1,\cdots,m$$
where $X_{(j)}^{s(J^{s+1})-e(J^{s})}$ and $Y_{(j)}^{e(J^{s+1})-s(J^{s+1})}$ are independent with
$$X_{(j)}^{s(J^{s+1})-e(J^{s})} \sim P(\lambda_j \cdot (s(J^{s+1})-e(J^{s}))),\,Y_{(j)}^{e(J^{s+1})-s(J^{s+1})} \sim P(\lambda_j \cdot (e(J^{s+1})-s(J^{s+1})))$$

Since $s(J^{s+1})-e(J^{s})>0$ if and only if  when all $m$ types do not satisfy the threshold, so $\forall t \in [e(J^s), s(J^{s+1})]$, $W_{(j)}^{e(J^s)}+X^t_{(j)}\leq n_j,\, \forall j \in \{1,\cdots,m\}$. We will use this property to construct a coupled process to dominate this. 

\begin{lemma}\label{lemma::multiple-type coupled dominace}
Define a coupled process $\tilde{W}^t_{(j)}$ with continuous time:
$$\tilde{W}_{(j)}^0=2n_j, \tilde{W}_{(j)}^{t+\Delta T_{[1,\cdots,m]}}= \max\{ 2n_j,\, \tilde{W}_{(j)}^t +X_{(j)}^{\Delta T_{[1,\cdots,m]}}-n_j \},\, X^{\Delta T_{[1,\cdots,m]}}_{(j)} \sim P(\lambda_j\cdot \Delta T_{[1,\cdots,m]}) $$
We have that $\tilde{W}^t\geq W^t,\,\forall t\geq 0$
\end{lemma}
Detailed proof is in Appendix~\ref{appendix_lemma::proof of multiple-type coupled dominace}. For the coupled process $\tilde{W}^t_{(j)}$, since the processing time of a batch containing all $m$ types $\Delta T_{[1,\cdots,m]}$ is the same under fixed thresholds $[n_1,\cdots,n_m]$:
$$\Delta T_{[1,\cdots,m]} =  d_0 + d_1 \cdot \sum_{j=1}^m n_j(l_j^\prime+1)\left( l_j+\frac{l_j^\prime}{2} \right) ,$$
we can use batch index $s$ for simplicity. So the coupled process is equivalent to
$$\tilde{W}^0_{(j)} = 2n_j,\, \tilde{W}^{s+1}_{(j)} = \max\{ 2n_j, \, \tilde{W}^s_{(j)}+X^s_{(j)} - n_j \}=\max\{ 2n_j, \, \tilde{W}^s_{(j)}+Y^s_{(j)} \},\, X^s_{(j)} \sim P(\lambda_j \cdot \Delta T_{[1,\cdots,m]})$$

1. When $ \Delta T_{[1,\cdots,m]} = \frac{n_j}{\lambda_j}$, we have that
$$\lambda_j\cdot \Delta T = n_j\Rightarrow \ex{}{Y^s_{(j)}}=0.$$
So by Lemma~\ref{lemma::throughput gap}, we have that
$$\ex{}{W^S_{(j)}}\leq \ex{}{\tilde{W}^S_{(j)}}\leq \lambda_j + \sqrt{\lambda_j S}, $$

and Proposition~\ref{prop::simple random walk, tight bound} shows that this bound is tight.

2. When $\Delta T_{[1,\cdots,m]} < \frac{n_j}{\lambda_j}$, the expectation $\ex{}{Y^s_{(j)}}<0$. The coupled process $\tilde{W}^s_{(j)}$ has a negative drift. Since
\begin{align*}
\text{Var}(Y^s_{(j)} )&= \text{Var}(X^s_{(j)} )  = \lambda_j \cdot \Delta T_{[1,\cdots,m]}\\
\left| \ex{}{Y^s_{(j)}} \right| &= n_j - \lambda_j\cdot \Delta T_{[1,\cdots,m]}
\end{align*}
By Kingman, we have that
$$\ex{}{W^S_{(j)}}\leq \ex{}{\tilde{W}^S_{(j)}}\leq 2n_j + \frac{\text{Var}(Y^s_{(j)} )}{2\left| \ex{}{Y^s_{(j)}} \right| } =2n_j+ \frac{\lambda_j \cdot \Delta T_{[1,\cdots,m]}}{2\cdot\left(n_j - \lambda_j\cdot \Delta T_{[1,\cdots,m]}\right)}$$

So when $C = M^*$, we have that $\pi = [\frac{n_1^*}{l_1^\prime+1},\,\cdots,\, \frac{n_m^*}{l_m^\prime+1}]$. This is a special case where all types satisfy the condition $\Delta T_{[1,\cdots,m]} = \frac{n_j}{\lambda_j}$. So with the union bound, we have the expected upper bound of the throughput gap to the $\text{Throughput}^*$ in (\ref{throughput_fluid_multiple}) under the fluid system.
$$\frac{1}{S}\sum_{j=1}^m \ex{}{W^S_{(j)}}\leq \frac{1}{S}\sum_{j=1}^m \lambda_j +\sum_{j=1}^m \sqrt{\frac{1}{S}\lambda_j} $$
Note that Proposition~\ref{prop::online policy expected throughput upper bound, multiple type} shows that this bound is tight.

In \textbf{Conventional Heavy-Traffic} case,
$$\frac{1}{S^{\zeta }}\sum_{j=1}^m \lambda_j^{\zeta } +\sum_{j=1}^m \sqrt{\frac{1}{S^{\zeta }}\lambda_j^{\zeta }}  =\frac{1}{\zeta S}\sum_{j=1}^m \lambda_j +\sum_{j=1}^m \sqrt{\frac{1}{\zeta S}\lambda_j} \to 0, \,\zeta \to \infty.$$
With the expected end-to-end latency
$$\frac{1}{S}\cdot\Delta T_{[1,\cdots,m]} \cdot \left(\sum_{j=1}^m \lambda_j +\sum_{j=1}^m \sqrt{\lambda_j\cdot S} \right) \sim \Omega(\sqrt{\frac{1}{S}})$$

When all $m$ types satisfy the condition $\Delta T_{[1,\cdots,m]} < \frac{n_j}{\lambda_j}$, the expected upper bound of the throughput gap is bounded:
$$\frac{1}{S}\sum_{j=1}^m \ex{}{W_S^{(j)}}\leq \frac{1}{S}  \sum_{j=1}^m \left(2n_j+ \frac{\lambda_j \cdot \Delta T_{[1,\cdots,m]}}{2\cdot\left(n_j - \lambda_j\cdot \Delta T_{[1,\cdots,m]}\right)}\right) $$
with the bounded expected end-to-end latency
$$ \Delta T_{[1,\cdots,m]} \cdot\frac{1}{S}\sum_{j=1}^m \ex{}{W_S^{(j)}}\leq \Delta T_{[1,\cdots,m]}\frac{1}{S}  \sum_{j=1}^m \left(2n_j+ \frac{\lambda_j \cdot \Delta T_{[1,\cdots,m]}}{2\cdot\left(n_j - \lambda_j\cdot \Delta T_{[1,\cdots,m]}\right)}\right) \sim \Omega(\frac{1}{S})$$

\begin{lemma}\label{lemma::solution to martingale exists}
There exists a solution \(\theta > 0\) to the equation
\[

\]
\end{lemma}

So when $\theta>0$ satisfies $\phi(\theta)=1$, $M^i_{(k)}$ is a martingale that starts at $M^0_{(k)}= e^{\theta\cdot 0}=1 $.

$$P(\max_{1\leq i
\leq t}\{ e^{\theta S^i_{(k)}} \}\geq a)\leq \frac{\ex{}{M^t}}{a} = \frac{\ex{}{M^0}}{a}= \frac{1}{a}.$$

$$P(\max_{1\leq i
\leq t}\{ e^{\theta S^i_{(k)}}\} \geq e^{\theta c})\leq \frac{1}{e^{\theta c}}  \Rightarrow P(\max_{1\leq i
\leq t}\{  S^i_{(k)}\} \geq c)\leq \frac{1}{e^{\theta c}} .$$

$$P\left(  W^t_{(k)}\geq c  \right) <P\left(  \tilde{W}^t_{(k)}\geq c  \right) = P(\max_{1\leq i
\leq t}\{  S^i_{(k)}\} \geq c - n_k)\leq e^{-\theta (c - n_k)}$$

So for $2\leq k\leq m, 0\leq t\leq T$, we have that
$$P\left(  W^t_{(k)}\geq c  \right)< e^{-\theta_k (c - n_k)}$$
where $\theta_k>0$ is the solution to $(1-p_k+p_ke^{\theta})^{n_{k-1}}=e^{\theta \cdot n_k}$

To determine the memory lower bound \( M \), we need to ensure that the memory consumption does not exceed \( M \) at any time \( t \in \{0, 1, \dots, T\} \) with probability at least \( 1 - \delta \). For each segment \( k \in \{2, \dots, m\} \) and time \( t \in \{0, \dots, T\} \), we have:

where \( \theta_k > 0 \) satisfies:

\[ (1 - p_k + p_k e^{\theta})^{n_{k-1}} = e^{\theta \cdot  n_k}. \]

There are \( m - 1 \) segments (from \( k = 2 \) to \( m \)) and \( T + 1 \) time steps (from \( t = 0 \) to \( T \)). \[ c_k = n_k + \frac{\ln\left( \frac{(m - 1) \cdot (T + 1)}{\delta} \right)}{\theta_k}, \]
So we have that:
\[ P\left( W^t_{(k)} \geq c_k \right) \leq \frac{\delta}{(m - 1) \cdot (T + 1)}. \]

\[ P\left( \bigcup_{k=2}^m \bigcup_{t=0}^T \{ W^t_{(k)} \geq c_k \} \right) \leq \sum_{k=2}^m \sum_{t=0}^T P\left( W^t_{(k)} \geq c_k \right)\leq (m - 1) \cdot (T + 1) \cdot \frac{\delta}{(m - 1) \cdot (T + 1)} = \delta \]
Thus:

\[ P\left( W^t_{(k)} \leq c_k \text{ for all } k \in \{2, \dots, m\}, t \in \{0, \dots, T\} \right) \geq 1 - \delta. \]

So the memory consumption is bounded:

\[ \text{Memory Consumption}^t = M^\pi + \sum_{j=2}^m W_t^{(j)} \cdot (l + l_{j-1}')\leq M^* + \sum_{j=2}^m c_j \cdot (l + l_{j-1}') \]

Define the memory bound \( \mathbf{M}^{T,\pi} \):
\[ \mathbf{M}_T = M^\pi + \sum_{j=2}^m n_j \cdot (l + l_{j-1}') + \sum_{j=2}^m \frac{\ln\left( \frac{(m - 1) \cdot (T + 1)}{\delta} \right)}{\theta_j} \cdot (l + l_{j-1}'). \]
This \( \mathbf{M}^{T,\pi} \) ensures that with probability at least \( 1 - \delta \), the memory consumption does not exceed \( \mathbf{M}^{T,\pi} \) at any time \( t \in \{0, 1, \dots, T\} \).

\subsection{Proof of Theorem~\ref{thm:nested_wait_heavy_traffic, time varying}}\label{appendix:: proof of nested optimality, time varying.}
For the first segment, the state transition rule is 
$$ W^{(1)}_{s+1} = W^{(1)}_{s} + Y^{(1)}_s  - n_1 \cdot \mathbf{1}\{ W^{(1)}_{s} + Y^{(1)}_s  \geq n_1 \},  Y^{(1)}_s \sim P( \Delta T_{ s-\text{th Batch} }\cdot \sum_{j=1}^m \lambda_j(s) )  $$
where $s$ denotes the batch index, and $\Delta T_{s-\text{th Batch}}$ denotes the cost of the inference of the $s-th$ batch. Since $\Delta T_{s-\text{th Batch}}\leq \Delta T_{s, \, [1,\cdots,m]}$, where $\Delta T_{s, \, [1,\cdots,m]}$ is the time cost of the inference of the $s$-batch containing all $m$ types, we can obtain a dominated process $\{\bar{W}^{(1)}_{s}\}$. Also notice that when thresholds $n_j, 1\leq j\leq m$ is fixed, the $\Delta T_{s, \, [1,\cdots,m]} \equiv \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m) $ is time invariant.
$$ \bar{W}^{(1)}_{s+1} = \bar{W}^{(1)}_{s} + \bar{Y}^{(1)}_s  - n_1 \cdot \mathbf{1}\{ \bar{W}^{(1)}_{s} + \bar{Y}^{(1)}_s  \geq n_1 \},  Y^{(1)}_s \sim P( \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j(s) )  $$
So we can construct a dominate process with time invariant arrival
$$ \tilde{W}^{(1)}_{s+1} = \tilde{W}^{(1)}_{s} + \tilde{Y}^{(1)}_s  - n_1 \cdot \mathbf{1}\{ \tilde{W}^{(1)}_{s} + \tilde{Y}^{(1)}_s \geq n_1 \},  \tilde{Y}^{(1)}_s \sim P( \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j^* )  $$
where $ \sum_{j=1}^m \lambda_j^*  = \sup_{s \in \mathbb{N}} \{  \sum_{j=1}^m \lambda_j(s)\}  $, and $n_1>  \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j^*$. We next define that $X^{(1)}_s = \tilde{Y}^{(1)}_s - n_1  $, and $\{ \tilde{W}^{(1)}_{s}\}$ is dominated by a Lindley process
$$ \overline{W}^{(1)}_{0} = 2n_1,\,  \overline{W}^{(1)}_{s+1} = \max \{  2n_1, \overline{W}^{(1)}_{s} + X^{(1)}_s \},\,\forall s\geq 0  $$
Then we have that
$$ W^{(1)}_{s}\leq \bar{W}^{(1)}_{s} \leq \tilde{W}^{(1)}_{s} \leq \overline{W}^{(1)}_{s}, \forall s \in \mathbb{N}.$$
Since $n_1>  \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j^*$, the process $\{\overline{W}^{(1)}_{s} \}$ has negative drift. Since 
\begin{align*}
    \text{Var}(X^{(1)}_s ) &= \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j^*\\
    \left|  \ex{}{X^{(1)}_s} \right| &= n_1 - \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j^*
\end{align*}
By Kingman Inequality, we have that
$$  \ex{}{W^{(1)}_s}\leq  2n_1 + \frac{\Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j^*}{2\left(n_1 - \Delta T_{ [1,\cdots,m]}(n_1,\cdots,n_m)\cdot \sum_{j=1}^m \lambda_j^*\right)} $$
Next we consider the $k$-th segment, $2\leq k\leq m$, the arrival process is 
$$Y^{(k)}_s \sim \text{Binomial}(n_{k-1},p_k(s)),\, \forall s\geq 0$$
So the state transition rule is given by
$$W^{(k)}_{s+1} = W^{(k)}_{s} + Y^{(k)}_{s} - n_k \cdot\mathbf{1}\{ W^{(k)}_{s} + Y^{(k)}_{s}\geq n_k \} $$
where $s$ denotes the $s$-th batch which contains segment $s-1$, since there is new arrival to segment $s$ if and only if the segment $s-1$ is contained in the former batch.

We set $X^{(k)}_s  =  Y^{(k)}_s - n_k, \forall s\in \mathbb{N}$. Although here the distribution of $Y^{(k)}_s\sim \text{Binomial}(n_{k-1},p_k(s))$ is time-varying, the coupling construction is still the same as Lemma~\ref{lemma::nested coupled process}

Then, we have that 
$$ \tilde{W}^t_{(k)}\geq W^t_{(k)},\,\forall t\in \mathbb{N} $$
\end{lemma}

\subsection{Proof of Proposition~\ref{prop:unknown_lower_bound}}\label{sec:proof_unknown_lower_bound}
We use the same example as in the proof of Proposition \ref{prop:lower_bound_FCFS}. Consider there are two types of prompts, where prompts of type $1$ with $l_1=1, l_1^\prime=1, \lambda_1=1$ and prompts of type $1$ with $l_2=1, l_2^\prime=2, \lambda_2=1$. \\
Firstly, we compute the fluid model, and the total memory usage and equilibrium equations are given by
$$M = 1.5n_1+2n_2,\, d_0+d_1\cdot (1.5n_1+2n_2) = \frac{n_1}{2}=\frac{n_2}{3}$$
Thus
$$K = \frac{d_0}{1-9d_1},\, n_1 = 2K,\, n_2=3K,\, M=9K$$
where $K$ represents the time cost of the batch inference. Without loss of generality, we set $K=1$, then $n_1=2, \,n_2=3,\,M=9 $. \\
Secondly, we consider the stochastic case, where $X^i_{(t)}\overset{i.i.d}{\sim} P(1), i=1,2$. Assume that at time $t$, the system is in equilibrium, Equilibrium batch at time $t$:
\begin{itemize}
    \item Type $1$:
    \begin{itemize}
        \itemsep0em
        \item $1$ prompt in stage $0$, memory = $1$, just get prefilled
        \item $1$ prompt in stage $1$, memory = $2$, the memory will be cleared
    \end{itemize}
    \item Type $2$:
    \begin{itemize}
        \itemsep0em
        \item $1$ prompt in stage $0$, memory = $1$, just get prefilled
        \item $1$ prompt in stage $1$, memory = $2$
        \item $1$ prompt in stage $2$, memory = $3$, the memory will be cleared
    \end{itemize}
\end{itemize}
Then we consider the number of arriving prompts of each type $(X^1_{(t)}, X^2_{(2)})$. We cannot distinguish the two types unless type 2 prompt enters stage $2$. Consider all possible combinations of one batch, one can prove with easy discussion that, for each possible batch, it either under-utilizes the memory (i.e. there are expected arrivals greater than the completions during the iteration), or will have positive constant probability at least $\rho>0$ of memory overflow (i.e. the total memory of output will exceed the memory capacity). Moreover, the throughput is counted only after the prompt is completed. Since the fluid throughput in equilibrium equals to the expected arrivals' output length in unit time, the throughput gap is at least $\Omega(\rho).$
