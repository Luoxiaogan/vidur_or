\ABSTRACT{%
Large Language Models (LLMs) require significant computational resources for inference, especially due to the memory demands of the Key-Value (KV) cache. This paper tackles the problem of optimizing LLM inference with memory constraints by modeling it as a multi-stage online scheduling task with stochastic queueable requests. We introduce a fluid dynamics approximation as a performance benchmark and propose the Waiting for Accumulated Inference Threshold (WAIT) algorithm, which is a threshold-based policy to handle random prompt arrivals based on the fluid dynamics. The algorithm achieves near-optimal throughput while controlling latency and Time to First Token (TTFT). We also present a Nested WAIT variant for cases where prompt output lengths are unknown at arrival. Theoretical analysis shows that the algorithms are asymptotically optimal under heavy traffic. Experiments on synthetic and real-world datasets with Llama-7B on A100 GPU show that our approach outperforms standard scheduling methods in throughput and latency. This framework offers an efficient solution for LLM deployment, with practical value for utilizing operations research methods to optimize LLM inference.
