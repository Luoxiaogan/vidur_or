**CustomPromptGenerator 核心逻辑**:
```python
# 按 arrival_rate 权重随机选择请求类型
prompt_type_info = random.choices(
    self.prompt_types,
    weights=[pt["arrival_rate"] for pt in self.prompt_types],
    k=1

# 创建带 prompt_type 的 Request
return Request(
    arrived_at=arrived_at,

    num_decode_tokens=prompt_type_info["decode"],
```

### 2. 实体修改

#### `vidur/entities/request.py`
**新增属性和方法**:

```python
# 新增构造函数参数
prompt_type: str = "default"  # 请求类型标识

# 新增实例属性
self.prompt_type = prompt_type
self.current_stage = 0  # 当前处理阶段

# 新增方法
def advance_stage(self):
    """将请求推进到下一个阶段"""
    self.current_stage += 1

def reset_stage(self):
    """将请求阶段重置为 0"""
    self.current_stage = 0
```

**用途**: 支持 Nested Booking Limit 调度器按阶段管理请求。

## 三、修改总结

### 新增功能
1. **Booking Limit 调度器系列**: 4种新调度算法，支持按请求类型和阶段进行精细化调度
2. **自定义请求生成器**: 支持多类型请求按到达率生成
3. **请求阶段管理**: Request 新增 `current_stage` 属性和 `advance_stage()` 方法
4. **吞吐量指标**: 新增实时吞吐量跟踪和可视化

### 修改目的
- 实现基于 Booking Limit 的调度策略研究
- 支持多类型请求的公平性调度
- 增强指标收集和结果输出功能
