## 二、prompt_types 设计选项

### 格式定义

```python
prompt_types = [
    {"type": "type1", "prefill": 60, "decode": 50,  "arrival_rate": 230},
    {"type": "type2", "prefill": 60, "decode": 100, "arrival_rate": 110},
    {"type": "type3", "prefill": 60, "decode": 150, "arrival_rate": 80},
    {"type": "type4", "prefill": 60, "decode": 200, "arrival_rate": 70},
    # ... 可添加更多类型
]
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | str | 请求类型标识 (如 "type1", "type2") |
| `prefill` | int | prefill 阶段的 token 数 |
| `decode` | int | decode 阶段的 token 数 (决定 segment 划分) |
| `arrival_rate` | int/float | 到达率权重 (按比例随机选择请求类型) |

### Nested Booking Limit 的 Segment 划分逻辑

根据不同 decode 长度自动划分 segment：
- **Segment 1**: 所有请求都会经过 (stage 0 到 decode_min)
- **Segment 2**: decode > decode_min 的请求继续处理
- **Segment 3**: decode 更长的请求继续处理
- ...以此类推

详见调度器实现：[nested_booking_limit_replica_scheduler.py](../vidur/scheduler/replica_scheduler/nested_booking_limit_replica_scheduler.py)

## 四、请求生成模式

### 模式对比

| 模式 | 参数 | 说明 |
|------|------|------|
| **自定义生成** | `--request_generator_config_type custom` | 按 prompt_types 的 arrival_rate 权重随机生成请求 |
| **Trace+Poisson** | `--request_generator_config_type synthetic` + `--length_generator_config_type trace` | 长度从 CSV 文件读取，到达间隔使用 Poisson 分布 |

### 自定义生成器

实现文件：[custom_prompt_generator.py](../vidur/request_generator/custom_prompt_generator.py)

核心逻辑：
```python
# 按 arrival_rate 权重随机选择请求类型
prompt_type_info = random.choices(
    self.prompt_types,
    weights=[pt["arrival_rate"] for pt in self.prompt_types],
    k=1
)[0]
```

### Trace 数据文件

可用的 trace 文件位于 `data/processed_traces/` 目录：
- `sample_2e5_input<200_output<500.csv`
- `sample_5e5_input<200_output<500.csv`
- `splitwise_code.csv`

## 五、快速运行示例

### 示例 1: 自定义请求类型

```python
# run_test.py
from utils import run_nested

prompt_types = [
    {"type": "type1", "prefill": 60, "decode": 100, "arrival_rate": 16},
    {"type": "type2", "prefill": 60, "decode": 300, "arrival_rate": 8},
    {"type": "type3", "prefill": 60, "decode": 500, "arrival_rate": 4},
]

run_nested(
    destination_folder="./test_output",
    limit_start=100,
    limit_end=101,      # 只跑一次 (limit=100)
    limit_interval=1,
    num_requests=1000,
    prompt_types=prompt_types,
)
```

### 示例 2: 使用真实 Trace 数据

```python
from utils import run_nested_real_data

prompt_types = [
    {"type": "type1", "prefill": 60, "decode": 100, "arrival_rate": 16},
    {"type": "type2", "prefill": 60, "decode": 300, "arrival_rate": 8},
    {"type": "type3", "prefill": 60, "decode": 500, "arrival_rate": 4},
]

qps = sum(pt['arrival_rate'] for pt in prompt_types)  # 总 QPS

run_nested_real_data(
    destination_folder="./test_output",
    limit_start=128,
    limit_end=129,
    limit_interval=1,
    num_requests=8000,
    prompt_types=prompt_types,
    qps=qps,
    trace_file="./data/processed_traces/sample_5e5_input<200_output<500.csv",
)
```

### 示例 3: Shell 脚本直接运行

```bash
# 运行 Nested Booking Limit
bash test_nested_booking_limit.sh

# 运行基础 Booking Limit
bash test_booking_limit.sh
```

## 六、输出结果

模拟结果输出到 `simulator_output/` 目录，包含：
- `throughput*.csv` - 吞吐量数据
- `plots/` - 各类指标的 CSV 和可视化图表
  - `request_e2e_time*.csv` - 端到端延迟
  - `request_completion_time_series*.csv` - 完成时间序列
  - `batch_size*.csv` - 批处理大小

[utils.py](../utils.py) 中的 `copy_latest_csv()` 函数会自动复制结果到指定目录。
