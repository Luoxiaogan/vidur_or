# GPT-Pro Final Revision Audit Packet

This folder contains the materials for an external final audit of the OPRE revision package.

## Files

1. `01_AE_report.pdf`  
   Associate editor report.

2. `02_review_report_1.pdf`  
   Full referee report 1.

3. `03_review_report_2.pdf`  
   Full referee report 2.

4. `04_decision_letter.md`  
   Decision letter text.

5. `05_original_submission.pdf`  
   Original submitted manuscript.

6. `06_revised_paper.pdf`  
   Current revised manuscript.

7. `07_response_letter.pdf`  
   Current response letter.

8. `08_internal_audit_checklist.md`  
   Internal checklist of previously identified audit risks and fixes.

9. `PROMPT.md`  
   Suggested prompt to paste into GPT-Pro / Deep Research.

## Audit Goal

Ask GPT-Pro to evaluate whether the revised manuscript and response letter adequately address the AE/referee/decision-letter concerns, with particular attention to exposition, language, logical consistency, claim scope, proof coverage, experiment-response alignment, and remaining resubmission risks.
