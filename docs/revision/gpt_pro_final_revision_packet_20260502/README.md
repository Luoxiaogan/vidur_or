# GPT-Pro Final Revision Audit Packet

This folder contains the core materials for a final external audit of the OPRE revision package.

## Files

- `01_AE_report.pdf`: Associate Editor report.
- `02_review_report_1.pdf`: Referee report 1.
- `03_review_report_2.pdf`: Referee report 2.
- `04_decision_letter.md`: Decision letter / editor comments.
- `05_original_submission.pdf`: Original submitted manuscript before revision.
- `06_revised_paper.pdf`: Current revised manuscript.
- `07_response_letter.pdf`: Current response letter.
- `PROMPT.md`: Suggested prompt to paste into GPT-Pro.

## Audit Goal

Check whether the revised paper and response letter fully address the editor/referee concerns, whether the response letter is aligned with the actual manuscript changes, and whether any language, logic, or claim-strength issue remains before submission.
